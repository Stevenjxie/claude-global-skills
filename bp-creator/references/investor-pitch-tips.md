# 投资人视角的 BP 写作技巧

## 投资人最关心的 5 个问题

1. **市场够大吗？** → TAM 至少 10 亿级，有明确增长趋势
2. **团队能做成吗？** → 创始团队有行业经验 + 互补能力
3. **时机对吗？** → 技术/政策/需求的窗口期
4. **壁垒在哪？** → 网络效应、数据、技术、品牌
5. **回报预期？** → 3-5 年 10x+ 回报可能性

## 常见致命错误

| 错误 | 正确做法 |
|------|----------|
| 市场规模用百度搜的 | 引用权威报告 (iResearch, Frost & Sullivan, Statista) |
| "我们没有竞争对手" | 诚实列竞品，突出差异化 |
| TAM = 整个行业规模 | TAM → SAM → SOM 逐层缩小，逻辑自洽 |
| 财务预测过于乐观 | 给出保守/基准/乐观三个场景 |
| 没有单位经济模型 | LTV/CAC > 3, 回本 < 12 个月 |
| 融资用途模糊 | 具体到岗位数、渠道预算、产品功能 |
| 只讲技术不讲商业 | 技术服务于商业价值，用数据说话 |

## Pitch Deck 黄金法则

### 10/20/30 规则 (Guy Kawasaki)
- **10** 页 (最多 15 页)
- **20** 分钟演讲
- **30** 号字体 (最小字号)

### 每页 Slide 的结构
```
标题: 断言句 (不是"市场分析"，而是"食品溯源市场 3 年内将达 500 亿")
正文: 1 个核心数据 + 1 个图表/图示
备注: 45-60 秒演讲稿
```

### 开场 30 秒模板
"[行业] 有一个 [X 亿元] 的问题: [痛点描述]。
[公司名] 通过 [核心能力]，已经为 [X 个客户] 解决了这个问题，
实现了 [核心数据]。
我们正在寻求 [X] 万元 [轮次] 融资，用于 [核心用途]。"

## 数据展示技巧

### 增长数据
- 用 MoM (月环比) 而非 YoY (同比) 展示早期增长
- 展示"J 曲线"趋势，标注拐点
- 对比行业平均增速

### 财务数据
- 用图表而非纯数字表格
- 标注关键假设和变量
- 给出盈亏平衡点

### 市场数据
- 用漏斗图展示 TAM → SAM → SOM
- 引用第三方数据源
- 标注自己的计算方法

## 不同轮次的侧重点

| 轮次 | 核心看点 | BP 侧重 |
|------|----------|---------|
| 种子轮 | 团队 + 方向 | 团队背景、市场洞察、MVP |
| 天使轮 | PMF 信号 | 早期用户数据、留存率 |
| Pre-A | 增长趋势 | MoM 增长、单位经济模型 |
| A 轮 | 规模化能力 | 营收数据、获客效率、团队扩展计划 |
| B 轮+ | 盈利路径 | 毛利率提升、市场份额、护城河 |

## 中国市场特殊考量

- **政策合规**: 突出符合国家战略方向 (如数字化转型、乡村振兴、碳中和)
- **本地化壁垒**: 如果是 to B，强调本地服务能力和客户关系
- **退出路径**: A 股 IPO / 港股 / 并购，明确路径
- **数据安全**: 如涉及数据，说明合规方案 (等保、GDPR 等)
